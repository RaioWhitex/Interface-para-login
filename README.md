# 🔐 Login Form UI

Uma interface moderna de formulário de login desenvolvida com foco em simplicidade, acessibilidade e experiência do usuário. O projeto apresenta um layout elegante para autenticação de usuários, com campos organizados, links de recuperação de senha e opções de cadastro.

---

## 📸 Preview do Projeto

Interface contendo:

- Formulário de login
- Campo para e-mail
- Campo para senha
- Link de recuperação de senha
- Botão de login estilizado
- Link para criação de conta
- Layout moderno e centralizado

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

## 🎨 Características do Design

## 🚀 Objetivo do Projeto

Praticar habilidades de desenvolvimento front-end através da criação de uma tela de autenticação moderna, explorando conceitos de formulários, alinhamento, estilização avançada e experiência do usuário utilizando HTML e CSS.

---

## 📚 Funcionalidades

- Entrada de e-mail
- Entrada de senha
- Recuperação de senha
- Botão de autenticação
- Link para cadastro de novos usuários
- Estrutura pronta para integração com sistemas de autenticação
- Compatibilidade com diferentes dispositivos

---

## 📱 Responsividade
